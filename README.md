# Swap3D Homebrew Tap

Official Homebrew tap for [Swap3D CLI](https://github.com/swap3d/swap3d-cli).

## Install

```bash
brew install --cask swap3d/tap/swap3d
```

## Upgrade

```bash
brew upgrade --cask swap3d
```

## Uninstall

```bash
brew uninstall --cask swap3d
```

The cask is generated from the checksums of each Swap3D CLI GitHub Release and
is synchronized automatically.
