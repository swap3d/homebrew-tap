# AGENTS.md

This repository is the official Homebrew tap for Swap3D CLI.

## Source Of Truth

`Casks/swap3d.rb` is generated by `swap3d/swap3d-cli` and published as a
GitHub Release asset. Do not hand-edit versions, URLs, or checksums.

The update workflow downloads the latest generated cask, validates it with
Homebrew, and commits it when it changes.

## Validation

```bash
brew style --cask swap3d/tap/swap3d
brew audit --cask swap3d/tap/swap3d
```

Only publish casks whose referenced release assets and SHA-256 values are
available from the public `swap3d/swap3d-cli` repository.
